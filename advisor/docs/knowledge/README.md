# 対戦知識の索引と調査手順

## 対戦ごとの参照手順

カード原文は先にローカルキャッシュを確認し、未保存ならYGOPRODeckから取得・保存します。[保存規則とコマンド](../card-knowledge-cache.md)を参照してください。原文取得と公式日本語名の照合、Master Duelでの効果・規制の確認は別の検証です。

1. 先に [基本ルールとターン進行](rules-and-turns.md) を読み、現在のターンプレイヤー・フェイズ・チェーンの状況を確認する。
2. 画面から読めたカード名を、確度付きで列挙する。カード画像が似ているだけなら「候補」に留め、未確認のカードや裏側カードは推測しない。
3. `themes/<テーマID>.md` があるか確認する。既存ガイドの確認日と対象カード・リミットレギュレーションが現状に合うか確認し、古ければ公式カードテキストと現行 Master Duel のゲーム内リミットレギュレーションで再確認する。
4. ガイドがなければ、まず公式カードデータベースで見えたカードの効果・発動条件・1ターン制限を調べる。展開例は公式公開デッキや信頼できる解説で照合し、OCG/TCGの構築例を Master Duel の合法デッキと混同しない。
5. 新しいテーマは `themes/_template.md` を複製し、識別根拠、基本展開、妨害候補、分岐条件、出典、確認日を記録する。
6. 実際の妨害判断は、見えたカードとその時点の盤面・チェーンに結び付ける。単なるテーマ名だけから「ここで必ず止める」と断言しない。

## ガイド一覧
